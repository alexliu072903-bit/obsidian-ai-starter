# Obsidian AI Starter

> One setup. Three superpowers for your Obsidian vault.

Turn Obsidian into a personal AI workspace — with your own API key, your own costs, your own rules.

## What you get

**1. Vault-aware AI at a fraction of the cost**
Pi runs inside Obsidian with full read/write access to your notes. Plug in DeepSeek, GPT-4o, or any LLM via your own API key. No subscription, no vendor lock-in. Switch models anytime without touching your vault setup.

**2. Your AI conversations become notes**
Every Pi session auto-saves to your vault as a searchable Markdown file in `Pi-Sessions/`. Your thinking, your AI interactions — all versioned, findable, and part of your knowledge base.

**3. A full agent, not just a chat window**
`/plan` to map out complex tasks before touching anything. `/loop` to iterate autonomously until a goal is reached. `/swarm` to run parallel sub-agents on different parts of a problem. These are things Claudian can't do.

## Quick Start

→ See [SETUP.md](SETUP.md) — paste it into Claude Code or Codex and it handles the automated parts. Manual steps take about 5 minutes in Obsidian.

**Prerequisites**
- Obsidian Desktop
- Node.js + npm
- Git
- An API key (DeepSeek recommended for cost, or OpenAI / Anthropic)
